# Contributing

JNB Recover is a scientific data-recovery project. Compatibility changes require reproducible evidence.

## Compatibility reports

When reporting an unsupported or incorrectly recovered JNB file, include the SigmaPlot generation if known, the observed result, and the expected worksheet structure or values when independently available.

Do not upload confidential, proprietary, personal, or otherwise restricted JNB files. Share only files and derived data that you have the right to disclose publicly.

## Scientific change rule

The accepted recovery engine is frozen. Changes to parser logic or cell semantics should include a fixture or independently verifiable reference demonstrating the current behavior is incorrect or incomplete.

Unknown encodings must remain unsupported or ambiguous until evidence supports a specific interpretation.

## Scope

Keep contributions focused on read-only SigmaPlot JNB worksheet-data recovery, validation, provenance, and low-maintenance offline workflows.
