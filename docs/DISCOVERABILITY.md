# Repository Discoverability

## English

This document records the recommended public metadata for JNB Recover. These settings improve discoverability without changing the accepted recovery engine or release artifact.

### Repository description

Recommended description:

`Recover scientific worksheet data from SigmaPlot JNB files locally and offline, exporting CSV and JSON with provenance.`

### Recommended topics

Use the following repository topics when possible:

`sigmaplot`, `jnb`, `data-recovery`, `scientific-data`, `scientific-software`, `data-extraction`, `data-conversion`, `interoperability`, `legacy-data`, `csv`, `json`, `python`, `ios`, `iphone`, `offline`

### Social preview

Recommended size: 1280 × 640 pixels.

The preview should communicate four ideas clearly:

* JNB Recover
* SigmaPlot JNB scientific data recovery
* Local and offline
* CSV + JSON with provenance

### Release page bilingual note

The existing `v0.5.2` release asset and tag should remain unchanged. The release body may be extended with a Simplified Chinese section that points to:

* `README.zh-CN.md`
* `RELEASE_NOTES_0_5_2.zh-CN.md`
* `docs/USAGE.zh-CN.md`
* `docs/TROUBLESHOOTING.zh-CN.md`
* `docs/VALIDATION.zh-CN.md`
* `docs/SCIENTIFIC_LIMITS.zh-CN.md`

### Search-oriented wording

Prefer accurate phrases such as:

* SigmaPlot JNB recovery
* scientific data recovery
* legacy scientific data
* worksheet extraction
* CSV and JSON export
* offline interoperability
* provenance-preserving recovery

Avoid claims that imply a complete JNB specification or guaranteed recovery of every notebook.
